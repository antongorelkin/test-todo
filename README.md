# Список задач (Todo List)

Простое приложение для управления списком задач, созданное на React + TypeScript с использованием Vite.

## Функционал

- ✅ Добавление новых задач через поле ввода
- ✅ Переключение статуса задачи (выполнена/не выполнена)
- ✅ Удаление задач
- ✅ Фильтрация: все задачи, активные, выполненные
- ✅ Автоматическое сохранение в localStorage
- ✅ Валидация: невозможно добавить пустую задачу или задачу из одних пробелов
- ✅ Визуальное различие между активными и выполненными задачами

## Технологии

- **React 18** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Vite** — быстрый инструмент сборки
- **CSS** — современные стили с градиентами и анимациями

## Установка и запуск

### Требования

- Node.js версии 18 или выше
- npm или yarn

### Инструкция

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Запустите приложение в режиме разработки:**
   ```bash
   npm run dev
   ```

3. **Откройте в браузере:**
   ```
   http://localhost:5173
   ```
   (Если порт 5173 занят, Vite автоматически выберет другой порт)

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`.

### Предварительный просмотр продакшен-сборки

```bash
npm run preview
```

## Основные возможности

### Добавление задачи
- Введите текст в поле ввода
- Нажмите кнопку "Добавить" или клавишу Enter
- Пустые задачи и задачи из пробелов не добавляются

### Управление задачами
- **Отметить выполненной:** кликните на чекбокс слева от задачи
- **Удалить:** нажмите красную кнопку с крестиком справа

### Фильтрация
- **Все** — показывает все задачи
- **Активные** — только невыполненные задачи
- **Выполненные** — только выполненные задачи
